# VRTrainingTest

Небольшой VR-тренажер на Unity. Проект сделан как прототип обучающего сценария: пользователь проходит несколько этапов, взаимодействует с объектами в сцене, получает обратную связь и в конце видит результат прохождения.

Визуальная часть намеренно простая. В сцене используются примитивы Unity, чтобы основной акцент был на логике VR-взаимодействия, последовательности действий и обработке ошибок.

## Как запустить

Проект открывается в Unity 6.6.

Для запуска нужно открыть сцену:

```text
Assets/VRTrainingTest/Scenes/Lobby.unity
```

В Build Profiles должны быть добавлены две сцены:

```text
0 - Lobby
1 - Training
```

Старт происходит из сцены Lobby. На меню нужно нажать кнопку начала тренировки, после этого загружается сцена Training.

## Управление

Проект тестировался через XR Device Simulator, у меня в наличии не были ни шлема ни джойстиков.

Основное управление:

```text
WASD / мышь - перемещение и обзор через симулятор
Shift (или Space для правой руки) + Left Mouse Button - действие лучом
Tab - переключение активного контроллера
G - grab / взятие объекта
```

Телепортация работает в Lobby и Training. В Training зона пола настроена как Teleportation Area.

## Сценарий тренировки

Сценарий состоит из трех групп. В каждой группе по три шага, которые нужно выполнять по порядку.

### Проверка документов

```text
1. Подойти к зоне проверки документов
2. Взять документ со стола
3. Нажать кнопку подтверждения документов
```

### Проверка оборудования

```text
1. Подойти к зоне оборудования
2. Кликнуть на неисправный объект
3. Нажать кнопку фиксации нарушения
```

### Завершение смены

```text
1. Подойти к зоне завершения
2. Взять финальный отчет
3. Нажать кнопку завершения тренировки
```

После завершения показывается экран результатов. В нем видно состояние каждого шага: выполнен, ошибка или пропущен. Также есть две кнопки: повторить тренировку и вернуться в лобби.

## Обратная связь

В тренажере есть несколько видов обратной связи:

- текущая группа и текущий шаг выводятся на world-space UI;
- нужный объект или кнопка подсвечивается миганием;
- правильное действие проигрывает высоий звук успеха;
- ошибка или нарушение порядка проигрывает низкий звук ошибки;
- результат каждого шага сохраняется до конца сценария.

Звуки создаются кодом, без внешних аудиофайлов.

## Ошибки и нарушение порядка

Если пользователь делает неправильное действие, текущий шаг помечается как ошибка, после чего сценарий переходит дальше.

Если пользователь выполняет действие из будущего шага текущей группы, это считается нарушением порядка. В таком случае текущий шаг помечается как ошибка, оставшиеся шаги группы помечаются как пропущенные, и тренажер переходит к следующей группе.

Это сделано специально, чтобы сценарий не зависал и пользователь мог пройти тренировку до конца даже после ошибки.

## Основные скрипты

```text
Assets/VRTrainingTest/Scripts/UI/SceneLoadButton.cs
```

Загружает сцену по имени. Используется в Lobby для перехода в Training.

```text
Assets/VRTrainingTest/Scripts/Training/TrainingScenarioController.cs
```

Главный контроллер сценария. Хранит группы шагов, принимает действия от объектов, проверяет правильность действия, отмечает статусы и завершает сценарий.

```text
Assets/VRTrainingTest/Scripts/Training/TrainingScenarioView.cs
```

Отвечает за UI тренировки: показывает текущую группу, текущий шаг, нужные кнопки и итоговый экран результатов.

```text
Assets/VRTrainingTest/Scripts/Training/TrainingReachPoint.cs
```

Отслеживает приближение игрока к нужной зоне. Проверка сделана по расстоянию до XR Origin, потому что у игрока в сцене нет обычного Character Controller с коллайдером.

```text
Assets/VRTrainingTest/Scripts/Training/TrainingGrabObject.cs
```

Регистрирует взятие объекта через XR Grab Interactable.

```text
Assets/VRTrainingTest/Scripts/Training/TrainingClickableObject.cs
```

Регистрирует клик по объекту через XRSimpleInteractable.

```text
Assets/VRTrainingTest/Scripts/Training/TrainingUIButton.cs
```

Передает нажатие UI-кнопки в сценарий.

```text
Assets/VRTrainingTest/Scripts/Training/TrainingHighlight.cs
```

Подсвечивает активный объект или кнопку. Цвет не заменяется полностью, а плавно смешивается с исходным цветом, поэтому объект мигает и остается читаемым.

```text
Assets/VRTrainingTest/Scripts/Training/TrainingResultActions.cs
```

Обрабатывает кнопки на экране результатов: перезапуск тренировки и возврат в Lobby.
